# product-inventory-system

Basic Spring Boot 3.3.5 project. Java 17+, Maven required.

## Run
Extract the ZIP, open the project folder containing pom.xml, then run:

```sh
mvn spring-boot:run
```

Or import as an existing Maven project in your IDE and run Application.java.
First run requires internet access to download Maven dependencies.

## Structure
One main class, one controller, one service class, one List-based repository,
one entity (plain Java model), one custom exception, one global exception handler.
No database, JPA, Lombok, DTOs, interfaces or service implementation layer.
Data is stored in memory and cleared on restart. IDs are generated by the server.
This exercise uses productId as the record ID.

## APIs
- GET http://localhost:8081/api/products
- GET http://localhost:8081/api/products/1
- POST http://localhost:8081/api/products
- PUT http://localhost:8081/api/products/1 (full update)
- DELETE http://localhost:8081/api/products/1

POST and PUT: select raw JSON with Content-Type: application/json.

```json
{"productName":"Keyboard","category":"Electronics","stock":10,"price":999.00}
```

POST returns 201; DELETE returns 204; missing records return 404;
validation failures return 400 with field messages. Mandatory numeric fields also
have @NotNull so omitted values return a validation error.
