# Library Book Management

Basic Spring Boot 3.3.5 exercise. Requires Java 17+ and Maven.
One main class, controller, service, repository, entity, custom exception and global exception handler.
No database, JPA, Lombok, DTOs or service interfaces. List-based storage resets on restart.
Book IDs are generated by the server. Numeric price and availability also have NotNull validation.

## Run
Open the extracted folder containing pom.xml and run:

```sh
mvn spring-boot:run
```

Or import as a Maven project into your IDE and run Application.java.
Internet is required for the initial dependency download.

## Endpoints
- GET /api/books : all books
- GET /api/books/1 : find one book
- POST /api/books : add book
- PUT /api/books/1 : full update
- PATCH /api/books/1/availability?available=false : update availability only
- DELETE /api/books/1 : delete book

Base URL: http://localhost:8082
POST/PUT body (Content-Type: application/json):

```json
{"bookName":"Java Basics","author":"Arun","price":450.00,"available":true}
```

## curl examples
```sh
curl -X POST http://localhost:8082/api/books -H 'Content-Type: application/json' -d '{"bookName":"Java Basics","author":"Arun","price":450.00,"available":true}'
curl http://localhost:8082/api/books
curl http://localhost:8082/api/books/1
curl -X PUT http://localhost:8082/api/books/1 -H 'Content-Type: application/json' -d '{"bookName":"Java Basics","author":"Arun","price":500.00,"available":true}'
curl -X PATCH 'http://localhost:8082/api/books/1/availability?available=false'
curl -X DELETE http://localhost:8082/api/books/1
```

Responses: POST 201, DELETE 204, missing book 404, validation failure 400.
ZIP integrity and project structure checked; Maven build/runtime not tested in the generation environment.
